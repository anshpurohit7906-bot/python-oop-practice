# Market Pipeline

A beginner financial data analysis project built using Python, Pandas, and Object-Oriented Programming.

## ✨ Features
* Create and manage market data using Pandas DataFrames
* Calculate average stock prices
* Analyze trading volume
* Filter stocks based on custom conditions
* Structured using OOP principles
* Generate multi-layered data visualizations (Bar & Line charts)
* Analyze chronological time-series trends using rolling calculations

## 🛠️ Technologies Used
* **Language:** Python
* **Libraries:** Pandas, Matplotlib
* **Version Control:** Git & GitHub
